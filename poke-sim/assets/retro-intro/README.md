# Retro Opening

Decorative Gengar versus Nidorino homage, not battle-engine output or a ROM recording.
Original-era sprites are redistributed unmodified from PokeAPI's sprite collection:

- https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/versions/generation-i/red-blue/back/94.png
- https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/versions/generation-i/red-blue/33.png

Pokemon artwork belongs to its respective rights holders; the application license does
not grant ownership of this artwork. Review artwork permissions before commercial release.
The animation is authored CSS, has no audio or flashing, and respects reduced motion.
Files are served locally; offline availability depends on the site's asset caching.
